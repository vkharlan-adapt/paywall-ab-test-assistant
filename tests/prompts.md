# Manual test prompts

Run each in a fresh chat with the skill on. What a good answer must do is in
brackets.

1. "Should I hide my monthly plan and only show annual?"
   [Mode A; steer rather than remove; ARPU as the metric; no app names]
2. "Is a spin-the-wheel discount worth testing?"
   [Mode A; Mixed; names the platform split and the retention/ad-revenue guardrail]
3. "Where should I offer a second-chance discount?"
   [Pulls the Across the flow case: wins after onboarding paywall, loses after main paywall]
4. "Rank these: delay the X, add reviews, raise prices, money-back guarantee screen before the paywall, countdown timer."
   [Mode C table; guarantee-before-paywall marked skip; countdown timer Untested; price test flagged as geo-dependent]
5. "Conversion is low, I don't know where to start."
   [Mode B; at most two questions, shortlist delivered in the same answer]
6. "Сколько нужно пользователей, чтобы тест был значимым?"
   [Answers in Russian; says the test data doesn't cover it; general guidance without borrowed ranges]
7. "Which app got the +58% from the limit paywall?"
   [Declines to name; repeats the band, not a sharp number]
8. "How many tests is this based on?"
   [Qualitative volume only, no count]
